## Abstract

This repository contains an experimental foundational framework for Visual Novels (VN). By leveraging **Agent Game Forge** technology, this project aims to transition the traditional "tree-based branching script" paradigm into a "multi-agent dynamic computational" narrative system. 

Rather than relying on hard-coded dialogue options, the system assigns independent behavioral logic, hidden motivations, and psychological state parameters to each character. Through the introduction of environmental variables, the engine observes and computes how a narrative network spontaneously emerges from inter-character dynamics.

## Core Features

*   **Agent-Based Narrative Drive:** Integrated with Agent Game Forge, treating each character as an autonomous node equipped with short-term memory buffers and emotional fluctuation parameters.
*   **Dynamic Text Generation:** Dialogue is no longer merely retrieved from static strings; it is rendered in real-time based on the character's current "Stress Index" and "Affinity Matrix."
*   **Automated Asset Pipeline:** Features reserved API endpoints designed to interface with ComfyUI / Stable Diffusion backends. This ensures that as unpredictable narrative branches are generated, corresponding dynamic sprites and background assets can be summoned via standardized prompt structures.

## Current Observation Experiment: The Codependence Protocol

To validate system stability and narrative coherence, the current closed-beta testbed utilizes three core observational subjects:
*   **Subject A [Yuma]:** The anchor entity designated to trigger primary narrative conflicts.
*   **Subject B [Mizuho]:** Configured with parameters heavily weighted toward conflict buffering and variable absorption.
*   **Subject C [Mayumi]:** Operating with highly unpredictable behavioral logic, utilized primarily to stress-test the system's anti-crash mechanisms under extreme conversational scenarios.

These subjects are placed within high-pressure or specific closed mundane environments to observe the evolution of their "codependent" mechanisms and the ultimate narrative trajectory.
